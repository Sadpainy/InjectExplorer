Injection Explorer

Android system permission controller & input injection framework

Overview

Injection Explorer is a command-line tool designed for security research, system debugging, and advanced automation on Android devices. It provides direct access to 28 system-level permissions, input event injection, display capture, and SurfaceFlinger / InputFlinger control.

Built for researchers, engineers, and power users who need transparent visibility and control over Android runtime behavior.

Core Capabilities

Permission Control

Grant, revoke, and audit 28 signature-level Android permissions including INJECT_EVENTS, CAPTURE_VIDEO_OUTPUT, and ACCESS_SURFACE_FLINGER.

Input Injection

Inject touch, key, swipe, text, and pointer events directly into the system input pipeline. Supports both global and process-targeted injection.

Display Capture

Capture screenshots, screen recordings, display buffers, and secure displays. Includes framebuffer read and pointer event capture.

SurfaceFlinger Control

Inspect and modify layer properties, transaction states, power modes, and display configurations through the ISurfaceComposer interface.

InputFlinger Access

Monitor and control the native input pipeline—EventHub, InputReader, and InputDispatcher—with full visibility into device events.

Audit & Logging

Comprehensive operation logging with session tracking, audit trails, and integrated logcat filtering for debugging and compliance.

Supported Permissions

Injection Explorer works with 28 real Android system permissions, all verified against AOSP source. These include:

  • INJECT_EVENTS, INJECT_PROCESS_EVENTS, INJECT_INPUT_EVENTS
  • INTERCEPT_KEY_EVENTS, CONSUME_KEY_EVENTS, FILTER_EVENTS
  • CAPTURE_VIDEO_OUTPUT, CAPTURE_SECURE_VIDEO_OUTPUT
  • CAPTURE_AUDIO_OUTPUT, CAPTURE_MEDIA_OUTPUT
  • ACCESS_SURFACE_FLINGER, ACCESS_INPUT_FLINGER
  • MANAGE_SURFACE_FLINGER, MODIFY_SURFACE_FLINGER
  • CONTROL_INPUT_FLINGER, MODIFY_INPUT_FLINGER
  • INJECT_POINTER_EVENTS, CAPTURE_POINTER_EVENTS
  • SET_POINTER_CAPTURE, CONTROL_TOUCH_SCREEN
  • SET_TOUCH_SENSITIVITY, READ_FRAME_BUFFER
  • and more...

Getting Started

Download the Inject.sh script, push it to your Android device, and run it as root with SELinux set to permissive. The script works on Android 11 through 16, providing both interactive panel and command-line modes.
