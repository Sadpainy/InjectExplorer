Inject Explorer

Android permission injection & system control interface

Inject Explorer provides a unified command-line interface for Android system-level permission management, input event injection, display capture, and kernel service control. Designed for security researchers, system engineers, and advanced automation workflows.

  • 28 system signature permissions
  • Input injection & event capture
  • SurfaceFlinger / InputFlinger control
  • Interactive TUI & CLI modes
  • Root & SELinux enforcement
  • Full audit logging
